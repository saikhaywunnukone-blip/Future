## ၂။ Brand ရဲ့ ဇာတ်လမ်း / Concept (video မှာ ပြောလို့ကောင်းတဲ့ အချက်)

- **"White T-shirt + Black Jacket"** — YSL က Y ကို ယောကျ်ားလေး ဝတ်စုံရဲ့ အခြေခံ ၂ ခုကနေ အိုင်ဒီယာယူထားတယ်။
  - **အဖြူရောင် T-shirt** = လတ်ဆတ်တဲ့ အစပိုင်းအနံ့ (ပန်းသီး၊ ချင်း၊ ဘာဂမော့)
  - **အနက်ရောင် Jacket** = ရင့်ကျက်တဲ့ နောက်ပိုင်းအနံ့ (သစ်သား၊ နံ့သာ)
  - Brand က "ပထမဆုံး white & dark fougère" လို့ ကြွေးကြော်တယ်။
  - 💡 **Video ရိုက်ရင် ကိုယ်တိုင် အဖြူ T-shirt + အနက် jacket ဝတ်ရိုက်ပါ** — concept နဲ့ ကွက်တိဖြစ်ပြီး မှတ်မိလွယ်တယ်။
- **ကြော်ငြာ မျက်နှာတွေ** — 2017 မှာ လူငယ် ၃ ယောက် (Alexandre Robicquet, David Alexander Flinn, Loyle Carner)၊ 2019 မှာ Maroon 5 ရဲ့ **Adam Levine**၊ 2020 မှာ **Lenny Kravitz**။
  ကြော်ငြာ message က "ကိုယ့်ကြောက်ရွံ့မှုကို ရင်ဆိုင်၊ ကိုယ့်ပန်းတိုင်ဆီ သွား" ဆိုတဲ့ ရဲရင့်တဲ့ လူငယ် ပုံစံ။
- **"Y" ဆိုတာ** — Yves Saint Laurent ရဲ့ "Y" နဲ့ "Why?" (ဘာလို့လဲ) ဆိုပြီး မေးခွန်းထုတ်ရဲတဲ့ "Generation Y" လူငယ်တွေကို ရည်ညွှန်းတယ်လို့ ပြောကြတယ် ⚠️ — Hook အဖြစ် သုံးလို့ရတယ်: *"Y? ဘာလို့ ဒီရေမွေးကို လူတိုင်း ဝယ်ကြတာလဲ"*

## ၃။ Notes (အနံ့ အဆင့်ဆင့်)

| အဆင့် | Notes | မြန်မာလို ဘယ်လိုအနံ့လဲ |
|---|---|---|
| **Top** (ပထမ ၁၅–၃၀ မိနစ်) | Apple, Ginger, Bergamot (+ Elemi, Aldehydes ⚠️) | **ပန်းသီးစိမ်း** လို ချိုချဉ် လတ်ဆတ်တဲ့အနံ့ + **ချင်း** ရဲ့ စပ်ရှိန်းရှိန်း + **ဘာဂမော့** (လိမ္မော်/ရှောက်မျိုးနွယ်) ရဲ့ သန့်ရှင်းတဲ့ citrus။ Aldehydes က "ဆပ်ပြာသန့်သန့်" ခံစားမှုပေးတယ် |
| **Heart** (၃၀ မိနစ် – ၃ နာရီ) | Sage, Juniper Berries, Geranium | **Sage** = ဟင်းခတ်အမွှေးရွက် အနံ့ (ပူရှိန်းလို အေးစိမ့်စိမ့်၊ စိမ်းစိမ်း)။ **Juniper** = Gin အရက်ထဲက အနံ့လို ထင်းရှူးဆန်ဆန်။ **Geranium** = ပန်းနံ့ နည်းနည်း၊ အရွက်စိမ်းနံ့ |
| **Base** (နောက်ဆုံး ကျန်မယ့်အနံ့) | Amberwood, Tonka Bean, Cedar, Vetiver, Olibanum (Frankincense) ⚠️ | **Amberwood** = ခြောက်သွေ့ပြီး ပြင်းတဲ့ သစ်သားနံ့ (ကြာကြာခံစေတဲ့ အဓိကအရာ)။ **Tonka** = ဗနီလာလို ချိုချိုလေး။ **Cedar** = ခဲတံသစ်သား အနံ့။ **Vetiver** = မြက်အမြစ်/မြေကြီးစိုနံ့။ **Olibanum** = ဘုရားကျောင်း အမွှေးတိုင်လို နံ့သာ |

⚠️ **Note မတူတာ:** Retailer အများစု (Sephora UK, The Fragrance Shop, Alshaya) က base မှာ vetiver + frankincense + tonka လို့ ပြောတယ်။ Perfumebox က fir balsam (ထင်းရှူးစေး)၊ ambergris၊ musk လို့ ပြောတယ် — ဒါက အများစုနဲ့ မတူလို့ မယုံပါနဲ့။

**တစ်ကြောင်းတည်းနဲ့ ပြောရရင်:** *ပန်းသီးစိမ်း + ချင်းနဲ့ လတ်ဆတ်တောက်ပစွာ စပြီး၊ ဟင်းခတ်ရွက်စိမ်းနံ့ ဖြတ်ကာ၊ ချိုချိုလေး သစ်သားနံ့နဲ့ အဆုံးသတ်တဲ့ "သန့်သန့်ပြင့်ပြင့် ယောကျ်ားလေး" ရေမွေး။*

## ၅။ ဘယ်အချိန် / ဘယ်သူနဲ့ ကိုက်လဲ

- **Myanmar ရာသီ:**
  - ☀️ **နွေ (မတ်–မေ):** ရတယ်၊ နေ့ဘက်အတွက် ကောင်း — ဒါပေမယ့် **၂ ချက်လောက်ပဲ** ဖျန်းပါ၊ နေပူကြီးထဲ များများဖျန်းရင် base ရဲ့ အချိုက စူးလာနိုင်တယ်
  - 🌧️ **မိုး (ဇွန်–အောက်တိုဘာ):** အကောင်းဆုံး ရာသီတွေထဲက တစ်ခု
  - ❄️ **ဆောင်း (နိုဝင်ဘာ–ဖေဖော်ဝါရီ):** ရတယ်၊ ၃–၄ ချက် ဖျန်းလို့ရ — ညဘက် ဆောင်းအတွက်ဆို Y Le Parfum / Y Elixir က ပိုကိုက်တယ်
  - (နိုင်ငံခြား review တွေက spring / summer / fall အတွက် အကောင်းဆုံး၊ winter အေးအေးမှာ အားနည်းတယ်လို့ ပြောကြတယ်)
- **နေ့/ည:** နေ့ဘက် အဓိက၊ ညနေပိုင်း casual လည်း ရ
- **အခါသမယ:** ရုံး ✅ · ကျောင်း/University ✅ · နေ့ဘက် Date / casual date ✅ · နေ့စဉ် ✅ · ညဘက် formal ပွဲကြီး — အလယ်အလတ်
- **အသက်အရွယ် / ပုံစံ:** ၁၈–၃၅ လောက် လူငယ်၊ smart casual ဝတ်တတ်သူ၊ ရေမွေး အစပြုဝယ်သူ (beginner) အတွက်လည်း safe ဖြစ်တယ်
- **ဖျန်းနည်း:** လည်ပင်းဘေး ၂ ဖက် + ရင်ဘတ် (အင်္ကျီပေါ်) — ရုံးအတွက် ၂–၃ ချက်

## ၈။ အစစ်/အတု ခွဲနည်း

- **Batch code** — ဘူးအောက်ခြေနဲ့ ပုလင်းအောက်ခြေမှာ ရှိတယ်။ ဘူးပေါ်ကနဲ့ ပုလင်းပေါ်က **တူရမယ်**။ checkfresh / Scento လို batch decoder မှာ စစ်ကြည့်လို့ရ
  - ⚠️ Batch code မှန်ရုံနဲ့ အစစ်လို့ မဆိုနိုင် — အတုလုပ်သူတွေလည်း code အစစ်ကို ကူးတယ်။ **စာလုံးပုံနှိပ်ပုံ (font)** က အတုကို ပိုဖော်ပြတတ်တယ်
- **ဘူး** — အစစ်က ခိုင်ခံ့၊ ပုံနှိပ်ချက် ပြတ်ပြတ်သားသား၊ barcode ပါ၊ cellophane (ပလတ်စတစ်အုပ်) တင်းတင်းကျပ်ကျပ် သပ်သပ်ရပ်ရပ်
- **ပုလင်း** — ဖန်အထူ၊ လက်ထဲမှာ လေးလေး ခိုင်ခိုင်။ အတုက ပေါ့ပြီး မျက်နှာပြင် မညီတတ်
- **Spray** — အစစ်က အသံတိတ်တိတ်နဲ့ မှုန်မှုန်လေး ညီညီ ထွက်တယ်။ အတုက "ရှူး" အသံကျယ်ပြီး မညီ
- **ဈေး** — retail ဈေးထက် အများကြီး သက်သာနေရင် သံသယဝင်ပါ
- 💡 **Content idea:** "ကျွန်တော့်ဆိုင်က ရေမွေး အစစ်ဖြစ်ကြောင်း ဘယ်လိုစစ်လဲ" video — batch code ကို camera ရှေ့မှာ စစ်ပြ၊ ဒါက ယုံကြည်မှု အများဆုံး တည်ဆောက်ပေးမယ်

## ၁၂။ Customer မေးနိုင်တဲ့ မေးခွန်း (FAQ)

1. **EDT နဲ့ EDP ဘယ်ဟာ ဝယ်ရမလဲ?** — လတ်ဆတ်ပေါ့ပါးတာ၊ နွေရာသီ နေ့ဘက် အဓိကဆို EDT။ ပိုကြာကြာခံပြီး ချိုချိုလေး သစ်သားနံ့ ကြိုက်ရင် EDP။ ပထမဆုံး Y ဝယ်မယ်ဆို EDP က ပိုအသုံးဝင်တယ်။
2. **ဘယ်နှနာရီ ခံလဲ?** — Online မှာ ၆–၁၀ နာရီလို့ ပြောကြတယ်၊ ကျွန်တော် စမ်းကြည့်တာ ___ နာရီ။ (ကိုယ်တိုင်ဖြည့်)
3. **မိန်းကလေး ဝတ်လို့ရလား?** — Men's ရေမွေးပါ၊ ဒါပေမယ့် လတ်ဆတ်တဲ့ ပန်းသီး/သစ်သားနံ့ ကြိုက်တဲ့ မိန်းကလေးတွေလည်း ဝတ်ကြတယ်။
4. **နွေရာသီ ဝတ်လို့ရလား?** — ရတယ်၊ ၂ ချက်လောက်ပဲ ဖျန်းပါ၊ နေ့ဘက်အတွက် ကောင်းတယ်။
5. **အစစ်လား ဘယ်လိုသိမလဲ?** — Batch code စစ်ပြပေးမယ်၊ ဘူးနဲ့ ပုလင်း code တူကြောင်း ပြပေးမယ်၊ [ကိုယ့် source] ကနေ ယူတာပါ။
