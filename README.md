# ရေမွေး Review Business — Project Plan

ရောင်းမယ့်ရေမွေးတွေကို **Video review**၊ **FB page post**၊ နောက်ပိုင်း **ကိုယ်ပိုင် image** တွေနဲ့ ကြော်ငြာဖို့ project ပါ။
ရေမွေးတစ်ခုချင်းစီအတွက် AI က အချက်အလက်ရှာပြီး **Research Brief** တစ်ခု ပြင်ဆင်ပေးမယ်၊ အဲ့ brief ကနေ video script၊ caption၊ image idea တွေ ထုတ်မယ်။

```
ရေမွေးရွေး → AI research brief → ကိုယ်တိုင် စမ်းဝတ်/စစ်ဆေး → Script + Caption → ရိုက်/တင် → Comment တွေကနေ သင်ယူ
```

## ရေမွေး Review Studio (အားလုံး တစ်နေရာတည်း)

**https://claude.ai/artifact/QcBLs9HEwrqVyxHWMxPfiD** — `studio/perfume-studio.html`

- ရေမွေးနာမည် ရိုက် → **Brief ထုတ်** → notes၊ မြန်မာရာသီ၊ နှိုင်းယှဉ်ချက်၊ အစစ်/အတု၊ Reel script၊ FB caption၊ FAQ အကုန် ထွက်လာပြီး Library ထဲ သိမ်းထားမယ်
- **ကိုယ်တိုင်စမ်း** tab မှာ ရလဒ်ဖြည့် → script/caption ကို ကိုယ့်ရလဒ်နဲ့ ပြန်ရေးခိုင်း
- Caption ၃ မျိုး၊ AI image prompt၊ Markdown export
- အခြေအနေ (Research → စမ်းပြီး → ရိုက်ပြီး → တင်ပြီး) မှတ်ထားလို့ရ
- ⚠️ Studio ထဲက AI က web မရှာနိုင်ပါ ("AI draft")။ Web research နဲ့ source link ပါတဲ့ brief လိုရင် Claude Code ကို "Studio ထဲက ___ ကို web research လုပ်ပြီး update လုပ်ပေး" လို့ ပြောပါ ("Web research")

## ရေမွေးတစ်ခုအတွက် လုပ်ရမယ့်အဆင့် (Workflow)

1. **ရေမွေးရွေးပါ** — ကိုယ့်ဆိုင်မှာ stock ရှိပြီး လူမေးများတာကို ဦးစားပေးပါ။
2. **AI research** — `prompts/research-prompt.md` ထဲက prompt ကို Claude မှာ ကူးထည့်၊ ရေမွေးနာမည်နဲ့ concentration (EDT/EDP/Parfum) ပြောင်းထည့်ပါ။ Brief ကို `briefs/` ထဲ သိမ်းပါ။
3. **ကိုယ်တိုင်စစ်ပါ (အရေးအကြီးဆုံး)** — AI က အနံ့မခံနိုင်ပါဘူး။ Brief ထဲက "ကိုယ်တိုင်စမ်းရန်" အပိုင်းကို ကိုယ့်လက်ပေါ်ဖျန်းပြီး ဖြည့်ပါ —
   ပထမ ၁၅ မိနစ် ဘယ်လိုနံလဲ၊ ၂ နာရီကြာရင် ဘယ်လိုလဲ၊ ဘယ်နှနာရီခံလဲ၊ ဘေးကလူ သတိထားမိလား။
   **သင့် ကိုယ်ပိုင်အမြင်က review ရဲ့ အသက်ပါ။**
4. **Source မတူတာ စစ်ပါ** — Website တွေမှာ note list တွေ မတူတာ အမြဲရှိတယ် (YSL Y မှာလည်း တွေ့ရတယ်)။ Brief မှာ "⚠️ မသေချာ" လို့ မှတ်ထားတာတွေကို brand official site မှာ ပြန်စစ်ပါ။
5. **Script + Caption** — Brief ထဲမှာ AI ရေးပေးထားတဲ့ draft ကို ကိုယ့်လေသံနဲ့ ပြင်ပါ။
6. **ရိုက်/တင်ပါ** — Reel (30–60 စက္ကန့်) + FB post + Story။
7. **Comment ကနေ သင်ယူပါ** — လူမေးတဲ့မေးခွန်းတွေကို နောက် video ရဲ့ topic အဖြစ်သုံးပါ။

## Content အမျိုးအစား (Content Pillars)

တစ်ပတ်ကို ၃–၄ ခု တင်နိုင်ရင် ကောင်းပါတယ်။ အမျိုးအစား လှည့်တင်ပါ —

| အမျိုးအစား | ဥပမာ |
|---|---|
| **Full Review** | "YSL Y EDP — ဝယ်သင့်လား?" |
| **နှိုင်းယှဉ် (VS)** | "YSL Y vs Bleu de Chanel — ဘယ်ဟာ ကိုက်မလဲ" |
| **Myanmar ရာသီဥတု** | "နွေရာသီ ရုံးသွားဖို့ ရေမွေး ၃ မျိုး" / "ဆောင်းရာသီ ညဘက်အတွက်" |
| **စစ်/တု** | "အစစ်နဲ့အတု ဘယ်လိုခွဲမလဲ" — ယုံကြည်မှု တည်ဆောက်ဖို့ အကောင်းဆုံး |
| **ဘတ်ဂျက်** | "ကျပ် ___ အောက် ရေမွေးကောင်း ၅ မျိုး" |
| **ဘယ်လိုဖျန်းမလဲ** | ဘယ်နေရာ ဖျန်းရင် ကြာကြာခံလဲ၊ ဘယ်နှချက်ဖျန်းသင့်လဲ |
| **Q&A** | Comment ထဲက မေးခွန်းတွေ ဖြေ |

**Myanmar ရာသီဥတုနဲ့ ချိတ်ပြောတာ** က ကိုယ့် page ကို တခြား page တွေနဲ့ ကွဲပြားစေမယ့် အချက်ပါ —
နိုင်ငံခြား review တွေက "Spring/Fall" လို့ ပြောပေမယ့် မြန်မာမှာ **နွေ (မတ်–မေ)**၊ **မိုး (ဇွန်–အောက်တိုဘာ)**၊ **ဆောင်း (နိုဝင်ဘာ–ဖေဖော်ဝါရီ)** ဆိုပြီး ပြန်ဘာသာပြန်ပေးပါ။

## Business အတွက် သတိထားရမယ့်အချက်

- **အစစ်ပဲ ရောင်းပါ၊ source ကို ပြောပြနိုင်ပါစေ။** Review page တစ်ခုရဲ့ တန်ဖိုးက ယုံကြည်မှုပါ။ တုကြောင်း တစ်ခါ ပေါ်တာနဲ့ page ပျက်နိုင်တယ်။
- **ရောင်းသူဖြစ်ကြောင်း ပွင့်ပွင့်လင်းလင်း ပြောပါ** — "ဒါ ကျွန်တော်ရောင်းတဲ့ ပစ္စည်းပါ၊ ဒါပေမယ့် အားနည်းချက်ကိုလည်း ရိုးရိုးသားသား ပြောပြမယ်" ဆိုတာမျိုး။ အားနည်းချက်ပါ ပြောတဲ့ review ကို လူတွေ ပိုယုံတယ်။
- **Brand logo ကို ကိုယ့် page logo အဖြစ် မသုံးပါနဲ့**၊ "YSL official" လို့ ထင်စေမယ့် စာမျိုး မရေးပါနဲ့။ Review လုပ်တာ၊ ရောင်းတာကတော့ ရပါတယ်။
- **AI image သုံးတဲ့အခါ** — ပုလင်းပုံကို AI နဲ့ အတုမဆွဲပါနဲ့ (ပုလင်းပုံစံ မှားသွားရင် customer က တုတယ်ထင်မယ်)။ ပုလင်းက **ကိုယ်တိုင်ရိုက်တဲ့ ပုံ အစစ်**၊ နောက်ခံ/mood (ပန်းသီး၊ ချင်း၊ သစ်သား စတာ) ကိုသာ AI/Canva နဲ့ လုပ်ပါ။
- **Decant (5ml / 10ml ခွဲရောင်း)** — ပုလင်းကြီး ဈေးကြီးတဲ့အတွက် အရင်စမ်းချင်တဲ့လူတွေ အများကြီးရှိတယ်။ Review ကြည့်ပြီး decant ဝယ်၊ ကြိုက်ရင် ပုလင်းကြီးဝယ် — ဆိုတဲ့ လမ်းကြောင်းက ရောင်းအားကို တိုးစေနိုင်ပါတယ်။
