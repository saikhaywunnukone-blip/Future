# ရေမွေး Research Prompt

## သုံးနည်း
1. Claude (claude.ai သို့မဟုတ် app) ကို ဖွင့်ပါ။ **Web search ဖွင့်ထားပါ** (မဖွင့်ရင် AI က မှတ်မိသလောက်ပဲ ရေးမှာမို့ မှားနိုင်တယ်)။
2. အောက်က box ထဲက စာအကုန် ကူးထည့်ပါ။
3. `[ရေမွေးနာမည်]` နေရာမှာ ရေမွေးနာမည် **concentration ပါ** ပြောင်းထည့်ပါ — ဥပမာ `Dior Sauvage Eau de Parfum`။
   (EDT နဲ့ EDP က အနံ့ချင်း မတူတာ များတယ်၊ ဒါကြောင့် concentration ကို အမြဲထည့်ပါ)
4. ရလာတဲ့ brief ကို `briefs/[brand]-[name].md` အဖြစ် သိမ်းပါ။
5. **⚠️ မှတ်ထားတာတွေကို ပြန်စစ်ပြီး၊ "ကိုယ်တိုင်စမ်းရန်" အပိုင်းကို ကိုယ်တိုင်ဖြည့်ပါ။**

နောက်ထပ် မေးလို့ရတာတွေ (brief ရပြီးနောက်) —
- "Script ကို ပိုရယ်စရာကောင်းအောင် / ပို premium ဆန်အောင် ပြန်ရေးပေး"
- "ဒီရေမွေးနဲ့ [တခြားရေမွေး] VS video script ရေးပေး"
- "FB caption ၃ မျိုး ရေးပေး — တိုတို၊ အလယ်အလတ်၊ ရှည်ရှည်"
- "Canva/AI image အတွက် prompt ၅ ခု ရေးပေး"

---

## Prompt (ဒီအောက်က အကုန်ကူးပါ)

```
မင်းက ရေမွေး research assistant ပါ။ ငါက မြန်မာနိုင်ငံမှာ ရေမွေးရောင်းပြီး Facebook page မှာ review video နဲ့ post တွေ တင်တဲ့သူပါ။

ရေမွေး: [ရေမွေးနာမည်]

Web search သုံးပြီး ဒီရေမွေးအကြောင်း အသေးစိတ် ရှာပေးပါ။ Brand official site၊ Fragrantica၊ Parfumo၊ Basenotes၊ ယုံကြည်ရတဲ့ retailer (Sephora စတာ) နဲ့ review တွေကို ကြည့်ပါ။

စည်းကမ်း —
- Source တွေ မတူရင် (ဥပမာ note list မတူ၊ ထွက်တဲ့နှစ် မတူ) ⚠️ နဲ့ မှတ်ပြီး ဘယ် source က ဘာပြောလဲ ရေးပါ။ တစ်ခုကို ကိုယ့်ဘာသာ မရွေးပါနဲ့။
- "အချက်အလက်" (brand က ပြောတာ) နဲ့ "Community အမြင်" (review တွေက ပြောတာ) ကို ခွဲရေးပါ။
- မသိရင် "ရှာမတွေ့ပါ" လို့ ရေးပါ၊ မခန့်မှန်းပါနဲ့။
- EDT / EDP / Parfum version တွေ မရောပါစေနဲ့ — ငါမေးတဲ့ version ကိုပဲ အဓိကထား။
- မြန်မာလို ရေးပါ၊ ရေမွေး note နာမည်တွေ (Bergamot, Vetiver စတာ) ကို English နဲ့ထားပြီး ဘေးမှာ မြန်မာလို "ဘယ်လိုအနံ့လဲ" ရှင်းပြပါ။
- ရာသီကို မြန်မာ ရာသီ (နွေ မတ်–မေ / မိုး ဇွန်–အောက်တိုဘာ / ဆောင်း နိုဝင်ဘာ–ဖေဖော်ဝါရီ) နဲ့ ပြန်ဘာသာပြန်ပြောပါ။ မြန်မာက ပူပြီး စိုထိုင်းတယ်ဆိုတာ ထည့်စဉ်းစားပါ။
- ဈေးနှုန်းကို ငါကိုယ်တိုင်ဖြည့်မှာမို့ နိုင်ငံခြား retail ဈေး (USD) ကိုသာ ရည်ညွှန်းအဖြစ် ထည့်ပါ။

ဒီ အပိုင်းတွေ ပါတဲ့ brief ရေးပေးပါ —
၁။ အခြေခံ အချက်အလက် (brand, နာမည်, concentration, ထွက်တဲ့နှစ်, perfumer, fragrance family, ကျား/မ, size များ) — table နဲ့
၂။ Brand ရဲ့ ဇာတ်လမ်း / concept / ကြော်ငြာမှာ ဘယ်သူပါလဲ — video မှာ ပြောလို့ကောင်းမယ့် စိတ်ဝင်စားစရာ အချက် ၂–၃ ခု
၃။ Notes — Top / Heart / Base table၊ note တစ်ခုချင်းစီ မြန်မာလို ဘယ်လိုအနံ့လဲ၊ ပြီးတော့ "တစ်ကြောင်းတည်းနဲ့ ပြောရရင်" summary
၄။ Longevity နဲ့ Projection (community အမြင်၊ နာရီ အကြမ်းဖျင်း)
၅။ ဘယ်ရာသီ၊ နေ့/ည၊ ဘယ်အခါသမယ၊ ဘယ်အသက်အရွယ်နဲ့ ကိုက်လဲ၊ မြန်မာ ရာသီဥတုမှာ ဘယ်နှချက်ဖျန်းသင့်လဲ
၆။ ကောင်းကွက် ၃–၅ ခု / အားနည်းကွက် ၃–၅ ခု (ရိုးရိုးသားသား)
၇။ နှိုင်းယှဉ်ချက် — line ထဲက တခြား version တွေ၊ တခြား brand ယှဉ်ပြိုင်ဘက် ၂–၃ ခု၊ ဘာကွာလဲ
၈။ အစစ်/အတု ခွဲနည်း (batch code, ဘူး, ပုလင်း, spray, ဈေး)
၉။ Reel video script (60 စက္ကန့်) — အချိန် | ပြောမယ့်စာ | ရိုက်မယ့်ပုံ table။ ပထမ ၃ စက္ကန့် Hook က လူကို ရပ်ကြည့်စေရမယ်။ နောက်ဆုံးမှာ CTA (message ပို့ / comment ရေး)
၁၀။ FB post caption (မြန်မာလို၊ emoji နည်းနည်း၊ hashtag ၅–၈ ခု၊ ဈေးနှုန်းနေရာ [ဈေး] လို့ ချန်ထား)
၁၁။ ပုံ/Image idea — thumbnail၊ notes ပစ္စည်းတွေနဲ့ flat lay၊ အရောင် mood
၁၂။ Customer မေးနိုင်တဲ့ မေးခွန်း ၅ ခုနဲ့ အဖြေ
၁၃။ "ကိုယ်တိုင်စမ်းရန်" checklist (ငါ ကိုယ်တိုင် ဖြည့်မှာ — ဗလာထားပါ)
နောက်ဆုံးမှာ Sources — သုံးခဲ့တဲ့ link အားလုံး
```
